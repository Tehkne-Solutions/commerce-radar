# Commerce Radar v0.8.7 — Otimizador inteligente de orçamento

A v0.8.7 compara estratégias conservadora, equilibrada e otimizada para distribuir um orçamento virtual em reais entre oportunidades já simuladas.

## Métricas

- retorno esperado e ROI;
- risco agregado e pior caso;
- concentração e diversificação;
- eficiência ajustada ao risco;
- limites por oportunidade, canal, produto e fornecedor.

## Segurança funcional

O otimizador apenas produz recomendações explicáveis. Nenhum orçamento, campanha, produto, fornecedor, canal ou marketplace real é alterado automaticamente. Toda decisão permanece sob aprovação humana.

## API

```js
CommerceRadarBudgetOptimizer.optimize(10000, 'otimizada', {
  maxAssetWeight: 0.45,
  maxChannelWeight: 0.65,
  minInvestment: 100
});
```
