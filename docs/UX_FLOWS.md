# Fluxos de uso — Commerce Radar 0.2

## Descoberta

Visão geral → Radar de oportunidades → filtros → analisar ou criar teste.

## Diagnóstico

Oportunidade ou ideia própria → parâmetros comerciais → score → canais → plano de sete dias → salvar ou criar teste.

## Validação

Novo teste → pesquisa → conteúdo → conversão → validado ou descartado.

## Gestão

Comparativo → priorização → exportação CSV.

Testes reais → métricas → aprendizados → próxima ação → exportação CSV.

Backup → arquivo JSON com análises e testes.
