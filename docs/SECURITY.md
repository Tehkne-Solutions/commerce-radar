# Privacidade e segurança — versão 0.2

- A aplicação não coleta dados em servidor.
- Não utiliza cookies de rastreamento.
- Não possui autenticação ou credenciais.
- Análises e experimentos permanecem no LocalStorage do dispositivo.
- Conteúdo exibido a partir de entradas do usuário recebe escape antes de ser inserido em HTML dinâmico.
- Exportações são produzidas localmente pelo navegador.
- Nenhuma recomendação representa garantia de resultado financeiro.
- Futuras integrações deverão utilizar APIs oficiais e segredos somente no servidor.
